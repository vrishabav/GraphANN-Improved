# Experimentation and Results: HNSW vs Vamana

This document summarizes the implementation details of the Hierarchical Navigable Small World (HNSW) algorithm and presents a comparative analysis against the Vamana (DiskANN) implementation on the SIFT1M dataset.

## 1. HNSW Implementation Details

The Hierarchical Navigable Small World (HNSW) index was implemented as a core alternative to the Vamana graph index. Key architectural features include:

- **Multi-layer Graph Structure**: Implements a hierarchy of layers where Layer 0 contains all data points and higher layers contain exponentially fewer nodes, enabling logarithmic search complexity.
- **Probabilistic Layer Assignment**: Nodes are assigned to a maximum layer using a geometric distribution (level = floor(-ln(uniform(0,1)) * mL)), where mL = 1/ln(M).
- **Greedy Multi-layer Descent**: Search starts from a global entry point at the highest layer, performing greedy descent (ef=1) until it reaches the target insertion or search layer.
- **Beam Search (search_layer)**: At the target layer, a beam search (Algorithm 2) maintains a dynamic candidate set (frontier) and a result set of size `ef`.
- **Heuristic Neighbor Selection (Algorithm 4)**: Ensures graph connectivity and navigability by selecting neighbors that are closer to the node than to any already-selected neighbor, promoting edge diversity.
- **Bidirectional Edge Maintenance**: During construction, edges are added bidirectionally, with degree-constrained pruning to maintain the `M` (or `M0` for Layer 0) connectivity limit.

## 2. Experimental Setup

- **Dataset**: SIFT1M (1,000,000 vectors, 128 dimensions, float32).
- **Comparison Metric**: Recall@10, Average Latency (µs), P99 Latency (µs), and Average Distance Computations.

### Configurations Tested

#### HNSW
- **HNSW-A**: M=8, efC=100
- **HNSW-B**: M=16, efC=100
- **HNSW-C**: M=16, efC=200
- **HNSW-D**: M=32, efC=200

#### Vamana (DiskANN)
- **Vam-Baseline**: R=32, L=75, alpha=1.2, Exact float32
- **Vam-Baseline-ADC**: R=32, L=75, alpha=1.2, Quantized ADC
- **Vam-SoftPrune**: R=32, L=75, alpha=1.2, Soft Diversity Pruning (beta=0.5)
- **Vam-R64**: R=64, L=75, alpha=1.2, Quantized ADC

## 4. Analysis and Conclusion

- **Distance Computation Efficiency**: HNSW M=16 is significantly more efficient in terms of graph traversal, requiring ~7x fewer distance computations (265 vs 1905) to reach 97-98% recall compared to the Vamana baseline.
- **Latency Trade-off**: Despite the fewer computations, Vamana R=32 maintains lower query latency at high recall levels. This suggests that the Vamana search implementation is more cache-optimized or benefits from a more direct graph structure for the SIFT1M dataset.
- **Recall Frontier**: Vamana R=64 with ADC quantization provides the absolute highest recall (99.9%+) and handles high-accuracy requirements better than HNSW at the tested configurations.
